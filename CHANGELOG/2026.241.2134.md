# 2026.241.2134 — feat: register the punktfunk marketplace family

## Summary

Registers a `punktfunk` marketplace family.

punktfunk landed as a full image family — `box/punktfunk-host` in
`opencharly/distro-cachyos`, the `punktfunk` candy in `opencharly/layer-punktfunk`, and
the `punktfunk:` check verb in `opencharly/plugin-punktfunk` — but had **no family here**,
so its skills had nowhere to be projected. The generator is fail-closed on this:

```
skill %q declares family %q which the marketplace entity does not declare
(add it to the marketplace `families:` map)
```

Follows the established one-family-per-image-family pattern (`category: images`,
`profiles: [container]`) — the same shape as `openclaw` and `versa` beside it.

**Why not an existing family:** `selkies` is "the selkies-desktop family (Wayland desktop
in a container with VNC + Chrome)", which punktfunk is not — it is a host daemon with its
own protocol and a management plane, not a containerised desktop stream. Filing it there
would make the taxonomy say something untrue. The verb skill does go in the existing
`check` family, where it belongs.

## How tested

VALIDATE_EXIT=0

the two skill-bearing repos; that PR carries the drift-gate output.
