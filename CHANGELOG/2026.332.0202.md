**RCA claim:** the marketplace manifest descriptions are a PROJECTION of this entity's
`description:` field, so this file is the ONE source and the three manifests are generated
output.

- **(C1) edit this source and regenerate the consumer — WORKS.** The run above moved all
  three manifests, `shortDescription` included, on the real generator.

- **(C2) hand-edit a generated manifest — FAILS; one regeneration reverts it.** Run in the
