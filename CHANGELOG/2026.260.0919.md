# 2026.260.0919 — feat(marketplace): declare the ten command families for the missing skills

## Summary

Declares in the shared `marketplace:` families map the ten families the
previously-unskilled charly commands need, so their `skill:` entities (authored
in their serving plugin repos, sibling PRs) generate instead of hard-erroring in
the generator's `buildModel` (an undeclared `family:` is a fail-closed error).

**All ten additions, one atomic declaration** (the two commits squash on merge):

| Family | Serving plugin | Command |
|---|---|---|
| `cache` | plugin-cache | `charly cache` |
| `pod-verbs` | plugin-pod | `charly cp` / `charly volume` / `charly restart` (a new family because `pod` is already the kind-authoring family) |
| `pipeline` | plugin-pipeline | `charly pipeline` |
| `review` | plugin-review | `charly review` |
| `feature` | plugin-feature / plugin-box | `charly feature` |
| `authoring` | plugin-authoring | `charly box set/add-candy/…` |
| `candy` | plugin-candy | `charly candy` |
| `bpf` | plugin-bpf | `charly bpf` |
| `cardwire` | plugin-cardwire | `charly cardwire` |
| `agent` | plugin-agent | `charly tui` |

## How tested

**Gate that exercises the change (mutation test — the declaration is NOT
vacuous).** The generator's `buildModel` hard-errors on an undeclared family;
that is exactly the failure these declarations remove. Proved on a two-candy
probe root with the patched generator: with the family declared, generation
succeeds; removing the declaration makes generation fail on the consuming skill:
```
$ # probe: a candy with `x-skill: {family: cache}` + a marketplace declaring `cache`
$ /tmp/mp-test generate --root . --out ./out
marketplace generate: wrote 10 artifact(s) across 1 family(ies)

$ # mutate: delete the `cache:` family entry from the marketplace entity
$ /tmp/mp-test generate --root . --out ./out2
charly marketplace: skill "xprobe" declares family "cache" which the marketplace entity does not declare (add it to the marketplace `families:` map)
```

**Manifest gate on THIS repo (pasted):**
```
$ charly box validate
charly box validate: OK — checked 1 candy, 7 distros, 7 builders; 0 warnings, 0 errors
```
