# 2026.260.1207 — fix(marketplace): rename the candy family to candy-cli (source-dir collision)

## Summary

Renames the `candy` marketplace family to `candy-cli`, so it stops colliding with
this repo's own source tree. The family's `description:` is unchanged.

**The defect (root-caused).** This repo's source tree lives at `candy/`
(`candy/charly-marketplace/charly.yml` = the refs list). A family named `candy`
is emitted to `<family>/skills/<name>/SKILL.md` and `<family>/.claude-plugin/`,
i.e. straight into that source tree. The corpus regeneration proved it: it wrote
generated `candy/.claude-plugin/plugin.json` + `candy/.codex-plugin/plugin.json`
into the refs-source tree.
